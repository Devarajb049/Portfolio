## 🚀 About

This is a personal portfolio website to showcase my projects, skills, and contact details. It features a responsive design and smooth user experience.

## ✨ Features

- **Responsive Design**: Works perfectly on mobile, tablet, and desktop
- **Clean Layout**: Modern and minimalistic design
- **Smooth Animations**: Subtle transitions for a polished feel
- **Easy Navigation**: Quick access to sections like About, Projects, Skills, and Contact
